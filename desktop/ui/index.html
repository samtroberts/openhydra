OpenHydra is a drop-in endpoint for coding tools — OpenAI-compatible at http://127.0.0.1:16527/v1 and native Anthropic at http://127.0.0.1:16527. Connect wires a supported tool in one click; Connect & Run also starts it; Test sends a live 1-token check. Others: copy the snippet. All talk to the gateway directly — no proxy.
From the terminal: openhydra launch <tool> wires and runs it (= connect + run, like ollama run); openhydra connect <tool> just wires it (editors / headless). Each card shows the verb natural to that tool.
Choosing a model: use openhydra/auto (OpenHydra routes it) or a specific id. In your tool, send /models to list what's live and /model <id> to pin one — tools with their own /model command (Pi, OpenCode) instead take the id via --model <id>.
